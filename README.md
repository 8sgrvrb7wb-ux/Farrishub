# 🎮 FarrisHub - Educational Games & Safe Search

FarrisHub is a comprehensive educational platform designed for students that combines interactive learning games with a safe, curated search engine. Built with vanilla HTML, CSS, and JavaScript—no external dependencies required!

## 🎯 Features

### Educational Games
- **🧮 Math Master** - Test arithmetic skills with challenging math problems
- **📚 Vocabulary Quest** - Expand vocabulary with word meaning challenges
- **🔬 Science Trivia** - Discover fascinating facts about science and nature
- **🌍 Geography Genius** - Test knowledge of world capitals and landmarks

Each game includes:
- 5 carefully curated questions
- Instant feedback on answers
- Score calculation and performance analysis
- Encouraging messages based on results

### Safe Search Engine
- Curated database of educational resources
- Search by keyword or category
- 6 subject categories:
  - 📐 Mathematics
  - 🧪 Science
  - 📜 History
  - 🗺️ Geography
  - 💻 Coding
  - 📖 English
- Links to trusted educational platforms

### User Experience
- Responsive design (mobile, tablet, desktop)
- Smooth animations and transitions
- Intuitive navigation
- Fast loading times
- Accessibility-friendly design

## 🚀 Quick Start

### Option 1: Open Directly
Simply open `index.html` in your web browser!

### Option 2: Local Server
```bash
# Using Python 3
python -m http.server 8000

# Using Node.js (with http-server)
http-server
```

Then navigate to `http://localhost:8000`

## 🎮 How to Use

### Playing Games
1. Click "Play Games" button on homepage
2. Select a game from the available options
3. Answer questions one by one
4. Get instant feedback on your answers
5. View your final score and performance

### Using Search
1. Click "Search" button or navigate to search section
2. Enter a keyword or select a category
3. Browse through curated educational resources
4. Click on resources to visit trusted websites
